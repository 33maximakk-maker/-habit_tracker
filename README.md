# Трекер привычек (виджет)

Многоязычная консольная утилита для отслеживания выполнения ежедневных привычек.  
Позволяет добавлять привычки, отмечать их выполнение, просматривать прогресс за неделю и вести историю в локальном JSON-файле.

## Особенности
- Добавление и удаление привычек.
- Отметка выполнения привычки за текущий день.
- Просмотр списка всех привычек с прогрессом за последние 7 дней (визуальный индикатор).
- Автоматическое сохранение данных в JSON-файл.
- Возможность указать пользовательский файл данных.
- Статистика: общее количество выполнений, процент выполнения за неделю.
- Цветное отображение прогресса в терминале (где поддерживается).
- Поддержка аргументов командной строки для быстрого использования.

## Установка и запуск
Для каждого языка требуются соответствующие инструменты и зависимости.

### Запуск на разных языках

1. **Python**  
   Установка: `pip install colorama` (опционально).  
   Запуск: `python habit_tracker.py --add "Утренняя зарядка"`

2. **JavaScript (Node.js)**  
   Установка: `npm install commander chalk`  
   Запуск: `node habit_tracker.js --add "Утренняя зарядка"`

3. **Go**  
   Установка: модулей не требуется.  
   Запуск: `go run habit_tracker.go --add "Утренняя зарядка"`

4. **Rust**  
   Добавьте `clap`, `serde`, `serde_json`, `chrono` в `Cargo.toml`.  
   Запуск: `cargo run -- --add "Утренняя зарядка"`

5. **Java**  
   Используйте Gson (опционально).  
   Сборка: `javac -cp gson.jar HabitTracker.java`  
   Запуск: `java -cp .;gson.jar HabitTracker --add "Утренняя зарядка"`

6. **C# (.NET Core)**  
   Установка: `dotnet add package Newtonsoft.Json`  
   Запуск: `dotnet run -- --add "Утренняя зарядка"`

7. **C++ (Linux)**  
   Требуется компилятор с C++11 и библиотека `nlohmann/json`.  
   Сборка: `g++ -std=c++11 -o habit_tracker habit_tracker.cpp -ljsoncpp`  
   Запуск: `./habit_tracker --add "Утренняя зарядка"`

8. **Kotlin (JVM)**  
   Используйте Gson.  
   Сборка: `kotlinc -cp gson.jar HabitTracker.kt`  
   Запуск: `kotlin -cp .;gson.jar HabitTrackerKt --add "Утренняя зарядка"`

## Использование

Общие аргументы командной строки (везде, где поддерживается):

- `--add <название>` – добавить новую привычку.
- `--remove <название>` – удалить привычку (полное совпадение).
- `--check <название>` – отметить выполнение привычки сегодня.
- `--list` – показать список всех привычек с прогрессом за 7 дней.
- `--file <путь>` – использовать указанный файл для хранения (по умолчанию `habits.json`).
- `--reset` – удалить все данные.
- `--help` – справка.

Пример (Python):
```bash
python habit_tracker.py --add "Чтение 30 минут"
python habit_tracker.py --check "Чтение 30 минут"
python habit_tracker.py --list
